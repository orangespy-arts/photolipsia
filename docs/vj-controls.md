# 手柄 VJ 与 Hydra

运行项目预览后打开 `/?vj=1&scene=ruin`。点击页面，按手柄 A，再松开摇杆、扳机和肩键。

| 输入 | 功能 |
| --- | --- |
| 左摇杆 | 按视角前后移动、左右平移 |
| 右摇杆 | 转向与俯仰 |
| 十字键 ↑ / ↓ | 世界垂直升降 |
| LT | 反馈拖影强度 |
| RT | 扭曲 / 镜像混合强度 |
| LB / RB | 上一 / 下一效果预设，按住不会连续切换 |
| B | 立即恢复清晰画面，松开扳机与肩键后重新启用 |

三套预设：回声（噪声扭曲 + 回授）、波纹（振荡波扭曲 + 回授）、镜像（万花筒混合 + 回授）。松开扳机后效果逐渐退去。

界面提供预设选择、预览效果、清晰复位、速度调节和回到入口镜头。预览按钮以 65% 强度试用当前效果；实际演出前结束预览，让扳机接管。

失焦、断连或长时间停帧会停止移动并清除效果，恢复后需先松开控制。自由飞行没有碰撞约束；迷失位置可回到入口。

Hydra 1.4.0 从本地已安装依赖加载，不请求麦克风、不依赖 CDN。它在高斯渲染后处理同一画布；效果为零时直接显示原画。加载或渲染失败时回退原画，并显示重试提示。添加 `&hydra=0` 可仅使用自由飞行。

自动测试与页面预览不能代替真实手柄、目标分辨率和录屏负载的演出彩排。
