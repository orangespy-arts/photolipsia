# 手柄 VJ 与 Hydra

运行项目预览后打开 `/?vj=1&scene=s01`。点击页面，按手柄 A，再松开摇杆、扳机和肩键。

| 输入 | 功能 |
| --- | --- |
| 左摇杆 | 按视角前后移动、左右平移 |
| 右摇杆 | 转向与俯仰 |
| 十字键 ↑ / ↓ | 世界垂直升降 |
| LT | 反馈拖影强度 |
| RT | 扭曲 / 镜像混合强度 |
| LB / RB | 上一 / 下一效果预设，按住不会连续切换 |
| B | 立即恢复清晰画面，同时关闭下面所有按键效果、色相归零 |
| Start | 下一场景（黑场切换，第 10 场后回到第 1 场） |
| A（按住） | 反相闪白，松开淡出 |
| X（开/关） | RGB 色彩分离 |
| Y（开/关） | 万花筒叠加（独立于"镜像"预设） |
| Back（开/关） | 黑白高对比 |
| 十字键 ← / →（按住） | 色相往回 / 往前旋转，松开停留 |
| 左摇杆按下 L3（开/关） | 像素化 |
| 右摇杆按下 R3（按住） | 画面冻结（只剩拖影） |

Home 键不映射：Windows 上 Xbox 手柄的 Home 被系统占用，浏览器读不到。
按键效果叠加在当前预设之后，单独成后处理层，不进入拖影反馈；切场景不清除。
带音乐演出用 `/?vj=1&scene=s01&audio=show`（空格或按钮开始播放）。
表演模式：键盘 H 隐藏/显示控制台（鼠标一并隐藏），F 全屏；网址加 `&perform=1` 打开即隐藏。

三套预设：回声（噪声扭曲 + 回授）、波纹（振荡波扭曲 + 回授）、镜像（万花筒混合 + 回授）。松开扳机后效果逐渐退去。

界面提供预设选择、预览效果、清晰复位、速度调节和回到入口镜头。预览按钮以 65% 强度试用当前效果；实际演出前结束预览，让扳机接管。

失焦、断连或长时间停帧会停止移动并清除效果，恢复后需先松开控制。自由飞行没有碰撞约束；迷失位置可回到入口。

Hydra 1.4.0 从本地已安装依赖加载，不请求麦克风、不依赖 CDN。它在高斯渲染后处理同一画布；效果为零时直接显示原画。加载或渲染失败时回退原画，并显示重试提示。添加 `&hydra=0` 可仅使用自由飞行。

自动测试与页面预览不能代替真实手柄、目标分辨率和录屏负载的演出彩排。
