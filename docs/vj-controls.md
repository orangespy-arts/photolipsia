# 手柄 VJ 与 Hydra

界面语言：控制台（含首页入口、输出窗口、gamepad 检测页）自 2026-11-05 起为英文；场景名与预设名也用英文。本表按功能中文描述，括号内为界面上的英文原文。

运行项目预览后打开 `/?vj=1&scene=s01`。点击页面，按手柄 A，再松开摇杆、扳机和肩键。

| 输入 | 功能 |
| --- | --- |
| 左摇杆 (Left stick) | 按视角前后移动、左右平移 |
| 右摇杆 (Right stick) | 转向与俯仰 |
| 十字键 ↑ / ↓ (D-pad) | 世界垂直升降 |
| LT | 反馈拖影强度 |
| RT | 当前预设的强度（0 = 原画） |
| LB / RB | 上一 / 下一效果预设（共 10 种，循环），按住不会连续切换 |
| B | 立即恢复清晰画面，同时关闭下面所有按键效果、色相归零 |
| Start | 下一场景（第 10 场后回到第 1 场）。转场在面板选：Freeze dissolve（定格溶解，默认）/ Particle scatter（粒子散聚）；有声音时等下一个重拍再切，最多等 1 秒 |
| A（按住） | 反相闪白 (flash)，松开淡出 |
| X（开/关） | RGB 色彩分离 (RGB split) |
| Y（开/关） | 霓虹描边 (neon edge)：只留轮廓线并发霓虹光（青↔品红缓慢变化），其余压暗 |
| Back（开/关） | 黑白高对比 (mono) |
| 十字键 ← / →（按住） | 色相往回 / 往前旋转 (hue)，松开停留 |
| 左摇杆按下 L3（开/关） | 像素化 (pixel) |
| 右摇杆按下 R3（按住） | 画面冻结 (freeze，只剩拖影) |

Home 键不映射：Windows 上 Xbox 手柄的 Home 被系统占用，浏览器读不到。
按键效果叠加在当前预设之后，单独成后处理层，不进入拖影反馈；切场景不清除。
带音乐演出用 `/?vj=1&scene=s01&audio=show`（空格或按钮开始播放）。
天空：s02 空城 (Empty City)、s09 云海遗迹 (Cloud Ruins) 的扫描没拍到天空，用程序生成的云天空补上（颜色/云量/飘动速度在 `src/mapping/skyPresets.js` 里改数字）；其他场景不加。
出生点：每个场景加载后自动算一个在场景中间、离表面有距离的位置，并朝向有纵深的方向（加载黑场里完成）；"回到入口镜头" (Back to entrance view) 回到这里。网址带 `view=`（copy framing）时首场以手动为准。
麦克风：音乐面板"🎤 Switch to microphone"让画面跟现场声音走（首次会弹权限；麦克风不送喇叭；音乐暂停在原位置）；有多个输入设备时可在下拉框选外接声卡；"♪ Back to music"释放麦克风。
进度条：音乐面板时间下方的进度条随播放走，拖动后松开即跳到该位置（麦克风模式下不可用）。
选曲：音乐面板"Pick music file"可换成本地任意音频（wav/mp3/m4a/ogg/flac…），选好后点"▶ Start music"或按空格；刷新页面后回到默认曲目。
粒子幅度：键盘 ↑/↓ 调整粒子随音乐跳动的幅度（0–3 倍，每步 ×1.25，0 = 完全静止），与面板"♪ Particle amplitude (sound-linked)"滑杆同步。
效果律动：键盘 ←/→ 调整 Hydra 拖影/扭曲随音乐变化的强度（0–1，每步 0.05），与面板"♪ Effect sync (sound-linked)"滑杆同步。
表演模式：键盘 H 隐藏/显示控制台（鼠标一并隐藏，提示行显示 Performance mode · H console · F fullscreen），F 全屏；网址加 `&perform=1` 打开即隐藏。

十种预设（英文界面名，RT 推强度，LT 拖影所有预设通用；均不与按键层重复）：
1 Echo（噪声扭动）· 2 Ripple（斜向波浪）· 3 Vortex（绕中心卷）· 4 Tunnel（同心缩放）·
5 Scan glitch（横向条带错位）· 6 Strobe（黑场闪烁，越推越快）· 7 Posterize（海报色带）·
8 Print（纯黑白阈值）· 9 Split（2×2→4×4）· 10 Melt（画面自身位移融化）。

界面提供预设选择（下拉框，英文）、预览效果 (Preview effect)、清晰复位 (Restore clear picture)、速度调节 (Speed) 和回到入口镜头 (Back to entrance view)。预览按钮以 65% 强度试用当前效果；实际演出前结束预览，让扳机接管。

失焦、断连或长时间停帧会停止移动并清除效果，恢复后需先松开控制。自由飞行没有碰撞约束；迷失位置可回到入口。

Hydra 1.4.0 从本地已安装依赖加载，不请求麦克风、不依赖 CDN。它在高斯渲染后处理同一画布；效果为零时直接显示原画。加载或渲染失败时回退原画，并显示重试提示。添加 `&hydra=0` 可仅使用自由飞行。

自动测试与页面预览不能代替真实手柄、目标分辨率和录屏负载的演出彩排。

上游接入说明：https://github.com/hydra-synth/hydra-synth

## 双屏：笔记本控制台 + 外接屏输出

界面语言：控制台（含输出窗口、gamepad 检测页）自 2026-11-05 起为英文。

1. 笔记本上打开控制台：`/?vj=1&scene=s01&audio=show&console=1`（默认按 1920×1080 渲染，
   可加 `&res=1280x720` 降低负载）。左边是输出画面预览和完整键位表（正在生效的键高亮），
   右边是场景、效果、音乐与飞行面板。点 "Open output window" 打开输出窗口。
2. 把弹出的窗口拖到外接屏，双击（或按 F）全屏。输出窗口只有画面，
   没有文字和鼠标；它显示的是控制台合成好的实时画面，不需要焦点。
3. 点回控制台窗口继续演出——渲染、手柄、音乐都在控制台里。点输出窗口会让控制台失焦，
   飞行和效果暂停；点回控制台并松开摇杆即可恢复。
4. 输出窗口刷新或控制台刷新后会在约 1 秒内自动重新连上；输出窗口被关掉就再点一次按钮。
   状态行 "Output window: open/closed" 后跟推送/复制速率与中心像素诊断。
