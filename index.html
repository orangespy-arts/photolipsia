Explorer: click canvas to lock mouse; mouse aims, WASD moves, Esc releases.
Right-drag also aims when pointer lock is unavailable.
Viewing mode only: orbit (left) / pan (right or Shift) / wheel = zoom — needs ?spin=0.
"copy framing" puts the current camera+tf into the URL for sharing.
Buttons: the driver row switches drivers (one per click, page reloads);
Explorer defaults to ruin1.ply; movement waits for the scene to load.
Leaves grow from the configured ground plane; no seed PLY is needed.
Plant pool: 2400 persistent plants per session. Plants vary in shape: bass pulses, mids sway, highs flutter. The environment and glass ball stay unchanged.
tf places the source scene; it does not transform the world-space floor.
&mode=static freezes the environment in viewing mode too.
rec records the current visuals → .jsonl download;
playback replays a recording through the same pipeline.
